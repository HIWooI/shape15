# 진행 보고 — 2026-08-13 ~ 08-14

RGB 카메라 → 관절 인식 → 로봇 리타겟 → MuJoCo 표시 + TWIST 계열 정책 참조 출력.
상세 수치·실패 기록·재현 명령은 `PLAN.md`가 원본이고, 이 문서는 세션 성과 요약이다.

## 1. 웹 패널 멈춤 해결 — 검증 완료

프레임 간격 최대 **4017 ms → 308 ms** (p99 295 → 100), 실효 속도 8.6 → 16.1 FPS.
논블로킹 IK 교환(`IKLink`)이 마지막 원인이 맞았다. 기존 `replay_delay.py`로는 검증이
불가능했음을 발견하고(자체 블로킹 교환 + 워커 렌더 부재) `--ik_async`(라이브 경로)와
`--ik_render`(실제 멈춤 유발자인 MuJoCo 렌더 포함)를 추가해 재현·측정했다.

## 2. 웹 캘리브레이션 버튼

스트림 페이지의 **Calibrate** 버튼 → `GET /calibrate` → T-포즈 프롬프트 → 워커가
15프레임으로 뼈 스케일과 floor 재측정. 요청은 첫 confidence 값의 **부호 비트**로
전달되어 고정 크기 프로토콜이 그대로 유지된다.

실측으로 거른 함정 셋 — 공통 교훈은 "캘리브레이션이 솔버를 흔들면 안 된다":
- floor를 재측정 중 0으로 두면 로봇이 0.7 m 떠오르고 이후 회복 불가
- 이전 스케일을 유지하면 체격이 다른 사람이 사거리 밖으로 나가 더 나쁨
- 웜스타트 리셋은 재캘리브레이션에서만 이득 (최초에 걸면 G1이 281→338 mm로 악화)

결과: 1.4배 체격 교체 후 K1 **0.1 mm** 복귀. G1은 158 mm — 타겟은 정확(1.8e-7 m)하나
솔버가 더 나쁜 최소점에 남는 기록된 결함. `test_calibrate.py {g1,k1}` 회귀로 고정.

## 3. 정확도: 44.8° → 22.0° → IK ~19.6° / MLP 11.5°

- **교사(soma-retargeter) 출력을 처음으로 직접 검증** (`outputs/teacher_vs_ours.mp4`).
  비결은 twist DOF를 10–40° 밴드에 잡아두는 것이었다.
- **twist nullspace**: `rest_cost`의 관절별 가중치 한 줄. 로봇별 최적값
  `{"g1": 0.05, "k1": 0.1}`. dance 클립에서 K1 13.1→8.0°, G1 10.6→7.9°.
  저움직임 영상에선 중립 — 콘텐츠 의존적 이득임을 명시.
- `make_offsets.py`로 상수 오프셋 재적합(G1은 최초 생성).
- A-포즈 회귀: 최대 비대칭 148.1° → 31.8°, 타겟 오차 64 → 38 mm.
- **측정 정정**: 초기 보고 "6.7°"는 같은 클립에서 적합·평가한 부풀림(홀드아웃 ~17°),
  "G1 전이" 주장은 미측정이었음. 전부 재측정해 PLAN에 정정 기록.

## 4. Distillation — MLP가 IK를 이김

파이프라인: `make_labels.py`(다중 클립 → 스트리밍 입력·교사 출력 쌍, 정렬 assert,
클립당 서브프로세스로 OOM 해결, 재시작 가능) + `distill.py`(클립 단위 홀드아웃,
IK 기준선 동일 조건).

**핵심 발견: 학생은 용량이 아니라 정보가 부족했다.** 14점 입력은 15.4°에서 정체
(width·시간 컨텍스트·데이터 증가 모두 무효). 교사가 실제로 소비하는 `body_pose`
(SOMA 76관절 articulation, 라이브에서 매 프레임 공짜)를 주면 한 번에 9.5°.

**라이브 배선 완료**: `demo_webcam.py --mlp models/g1_retarget_mlp_v2.pt`.
인지 쪽에서 0.25M 파라미터 넷(CPU ~0.3 ms)이 관절각을 파이프에 얹고, 워커는 솔브
대신 Kabsch로 베이스만 맞춘다(0.34 ms). IK는 기본값으로 유지.

알려진 한계: MLP엔 IK의 confidence 가중 방어가 없어 몸이 크게 가려지면 추정기의
상상을 그대로 출력한다.

## 5. 솔버 방향 타겟 경로 — 측정으로 기각

`soma_frames`의 **뒤집힌 프레임 상수 발견·수정** (SOMA 정준 y-up을 카메라 프레임으로
conjugate해 "위"가 "아래"로 가고 있었음; 교정 정렬은 위치 유도 torso_frame과 4.4°
일치, 기존은 180° 오류). 그러나 교정해도 솔버는 17.1 → 16.4°로 미미 — 팔의
A-pose/rest 불일치(60–90°)와 다리 브랜치 플립(150–170°)이 메커니즘 한계.
이것이 네트워크 경로 선택의 근거.

## 6. 예측기 — 측정으로 보류

지연 보상용 예측기 3종(상수속도·상수가속·학습) 전부 손해. 132 ms 늦음의 포즈 비용이
+0.28°에 불과한데(리타게팅 격차 ~10°가 지배) 예측기는 1.6–2.5°를 지불한다.
기본 오차가 수 배 줄거나 훨씬 빠른 모션을 다룰 때 재검토.
